## 🌟 نظرة عامة على المشروع (Project Overview)
موقع ويب تسويقي فاخر من صفحة واحدة (Single Page Application / Landing Page) مصمم بأحدث معايير وتجربة المستخدم (UI/UX) لعلامة **"حلواني فيستيفال"** في قلب الهرم.
يجمع الموقع بين الفخامة الشرقية والعصرية الغربية، مع دعم كامل للغة العربية (RTL) ولمسات أنيقة بالإنجليزية.

- **شاشة استقبال ملكية (Splash Screen):** تظهر فور فتح الموقع بإشعاع ذهبي دوّار وأمواج نورانية فاخرة.
- **شعار البراند والتاج الذهبي ثلاثي الأبعاد:** يحمل اسم **«حلواني فيستيفال | Festival Pastry»** مع التاج الملكي البراق وشعار «أصل الحلو - كل يوم عرض جديد».

### 2. التوافق التام مع الهواتف وجميع الأجهزة (Mobile-First Experience)
- **شريط تنقل سفلي ذكي (Mobile Bottom Dock):** مصمم خصيصاً للهواتف الذكية للتحكم بيد واحدة (الرئيسية، المنيو، زر واتساب عائم بارز، سلة الطلبات مع عداد فوري، والفروع).
- **تصميم متجاوب 100%:** متوافق مع كافة الشاشات (iPhone، Android، شاشات التابلت، اللابتوب والشاشات الكبيرة بدقة 4K).
- **مشغل فيديو سينمائي تفاعلي (Cinema Video Modal):** يتيح مشاهدة فيديو صناعة التورت والحلويات بالعرض الكامل وبدقة فائقة بنقرة واحدة.

### 3. شريط الإعلانات والهيدر (Header & Navigation)

- روابط سريعة لجميع الأقسام بتمرير سلس (Smooth Scroll).

- **سلة طلبات تفاعلية متطورة (Interactive Shopping Cart):** تتيح للعميل اختيار أي أصناف وتحديد الكميات، ثم بضغطة زر تقوم بإنشاء رسالة واتساب منسقة بكامل تفاصيل الفاتورة واسم الفرع والعنوان وإرسالها مباشرة!
