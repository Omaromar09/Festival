ربط قاعدة بيانات Supabase الحية

ادمج قاعدة بيانات Supabase السحابية لمزامنة كل الأسعار والمنتجات فورياً

خطوات تشغيل قاعدة البيانات في خطوة واحدة:

  1. افتح حسابك في Supabase.com وأنشئ مشروعاً جديداً.
  2. انتقل إلى تبويب SQL Editor في القائمة الجانبية في Supabase.
  3. انسخ محتوى الملف المرفق في المشروع supabase-schema.sql والصقه هناك ثم اضغط Run.
  4. انسخ Project URL و anon / public key من قسم Project Settings -> API والصقهما في الحقول أعلاه.
  5. اضغط "حفظ المفاتيح وتفعيل الربط"، وستعمل لوحة التحكم والمتجر بشكل سحابي كامل وفوري!
